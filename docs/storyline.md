# 발표 스토리보드 (2026-09-02 초안, 동결 9/10)

한 줄 주장: **온보드 AI 크레이터 탐지기는 mAP가 아니라 착륙 오차 분포(CEP)로 평가해야
하며, 그 차이를 만드는 것은 추론 지연 τ다.**

기여 3개 (결론 슬라이드와 동일 문구 유지):
1. 실데이터(SLDEM·WAC·Robbins)+실렌더(Unity)+실측 τ로 닫은 **폐루프 CEP 평가 프레임워크**.
2. **지연 보상의 성립 조건 정량화**: 보상 시 τ ≤ 프레임 주기 전 구간에서 CEP 평탄
   (지연 자체는 흡수) — 성립 조건 3가지(정확한 타임스탬프·유효 측정률·관성 모델)와
   각각이 깨질 때의 대가를 실측.
3. **양자화·경량화의 역할 규명**: 측정 품질(σ·오검출률) 동급을 보정으로 통제하면 τ 격차는
   주기 이하에서 CEP에 들어오지 않는다(τ 스왑 불변) — 양자화의 이득은 지연 단축이 아니라
   **τ를 프레임 주기 아래로 유지하는 처리량 여유**(5 Hz 주기 200 ms: n INT8 195.7 ms만
   충족, n FP32 219.0 ms는 초과 → 유효 측정률 하락. 처리량 상한 1/τ는 아키텍처 불문).

  운용 가능 여부를 가름(처리량 상한 1/τ) — 기여 ③ 문구가 답. 정량 수치(5 Hz 48.7 vs 65.7 m)는
  직렬 모델 조건부라 슬라이드에서 제외, qa_facts의 촬영 아키텍처 항목으로 방어
- "데모 영상에서 원이 크레이터와 어긋나 보인다": 원은 **EKF 예측 포즈** 기준 카탈로그
  투영이라 어긋남 = 항법 예측 오차(연관 게이트 50 px가 흡수, EKF가 보정하는 대상).
  탐지 자체는 참값 라벨 대비 중심 거리 median 0.52 px·p95 1.3 px(val 137매칭,
  2026-09-02 검증) — 슬라이드 9 캡션에 색 의미(초록=매칭, 보라=미탐지/비매칭,
