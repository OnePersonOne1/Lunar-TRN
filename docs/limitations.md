# 연구 한계점 (보고서·슬라이드 반영용)

수치를 동반하는 항목은 results/의 산출값만 인용한다. 여기는 서술의 단일 소스.

## 1. 극지(고위도) 적용 불가

본 시뮬레이터는 위도 약 ±60° 밖의 극지 착륙에는 그대로 적용할 수 없다.

- **DEM 커버리지**: 지형 참값으로 쓰는 SLDEM2015가 ±60° 위도 범위만 제공한다.
  극지는 LOLA 극지 DEM(극평사도법)으로 대체해야 하며, 이 경우 §2.1의
  등장방형 평면 근사(x = R_m·Δlon·cos(lat0))가 극에서 퇴화하여 좌표계
  계약 자체의 재설계가 필요하다.
- **조명 조건**: 달 자전축 경사(≈1.5°) 때문에 극지방 태양 고도는 최대 약 2°에
  불과하다. 본 연구의 데이터셋은 태양 고도 10–60° 범위에서 domain
  randomization을 수행하므로 극지 조명은 학습·평가 분포 밖이다. 고도 2° 이하
  조명에서는 크레이터 내부가 대부분 그림자에 잠겨, 밝은 테두리·그림자 대비를
  근거로 하는 크레이터 탐지와 원형 투영 기반 자동 라벨의 전제가 깨진다.
- **함의**: 남극 자원 탐사(물 얼음) 수요로 극지 정밀 착륙 시도가 집중되고
  있으나, 극지 TRN은 그림자 패턴 매칭 등 별도 기법이 필요한 후속 연구
  주제이다. 본 연구는 중위도에서 폐루프 정량화 방법론을 확립하고, 극지
  확장은 향후 과제로 남긴다.

## 2. 기타 범위 한계 (CLAUDE.md §1에서 정의된 결선 전 단순화)

- 3-DOF 병진 동역학: 자세 동역학 없음, 카메라 nadir 고정.
- IMU bias 상태 미모델링: IMU-only 구간 드리프트 과소평가 가능.
- 데이터 연관은 EKF 예측 투영 최근접 방식(lost-in-space 매칭은 10월).
- t_go = T_f − t 고정, 최적 t_go 탐색 없음.
- 평면 착륙 판정(r_z ≤ 0), 지형 충돌·경사 미고려.
- 측정 통계가 보정 전이면 모든 그림에 "assumed measurement stats"로 표기.
