# Lunar-TRN 진행 현황 공유 (2026-09-02 갱신)

> 온보드 경량 AI 크레이터 탐지 기반 달 착륙 TRN(지형상대항법) 폐루프 시뮬레이터.
> **핵심 주장 한 문장: AI 탐지기를 mAP(탐지 정확도 지표)가 아닌 "착륙 오차 분포(CEP)"로 평가한다.**
> 저장소: https://github.com/OnePersonOne1/Lunar-TRN

## 1. 이 프로젝트가 뭘 하는가 (30초 요약)

달 착륙선이 하강하면서 카메라로 지표의 **크레이터를 AI로 탐지**하고, 미리 알고 있는 크레이터 지도(카탈로그)와 대조해 **"내가 지금 어디에 있는지"를 계산**해서 목표 지점에 정확히 내려앉는 시스템을 시뮬레이션한다.

기존 연구들은 AI 탐지기를 "크레이터를 얼마나 잘 찾았나(mAP)"로만 평가한다. 우리는 한 걸음 더 나가서 — **AI의 추론 지연(τ)과 오검출이 실제 착륙 지점 오차에 얼마나 영향을 주는지**를 수백 번의 몬테카를로 시뮬레이션으로 정량화한다. 이게 이 연구의 차별점이다.

### 용어 미니 사전

| 용어 | 뜻 |
|---|---|
| **TRN** | Terrain Relative Navigation. 지형(크레이터)을 보고 자기 위치를 알아내는 항법 |
| **CEP** | Circular Error Probable. 착륙 지점들의 50%가 들어오는 원의 반경. 작을수록 정확 |
| **τ (타우)** | AI가 사진 한 장을 처리하는 데 걸리는 시간(추론 지연). 이 시간 동안 착륙선은 계속 움직이므로 "낡은 정보"로 항법하게 됨 |
| **EKF** | 확장 칼만 필터. IMU(관성센서)와 카메라 측정을 융합해 위치·속도를 추정하는 필터 |
| **지연 보상** | τ만큼 낡은 측정이 도착했을 때, 과거 시점으로 되돌아가 보정 후 현재까지 다시 계산하는 기법. τ의 1차 효과를 흡수하지만 **성립 조건 3가지(정확한 촬영시각 태깅, τ<촬영 주기, 정확한 관성 모델)가 있다는 것**이 핵심 결과 |
| **ZEM/ZEV** | 착륙 유도 법칙. 목표점에 위치·속도 오차 0으로 도달하도록 추력을 계산 |
| **INT8 양자화** | AI 모델의 숫자 정밀도를 32비트→8비트로 줄여 온보드 컴퓨터에서도 빠르게 돌게 하는 기법 |
| **PnP** | 사진 속 크레이터 위치들 ↔ 지도상 3D 좌표를 대응시켜 카메라(=착륙선) 위치를 역산하는 기하 문제 |

### 전체 파이프라인

```
물리 시뮬(RK4 동역학) → Unity 렌더(달 표면 사진 생성) → YOLO 크레이터 탐지(+INT8)
→ 카탈로그 매칭·PnP(위치 계산) → EKF(지연 보상+이상치 게이트) → ZEM/ZEV 유도 → 추력
→ (다시 물리 시뮬로) … 착륙까지 반복 → 수백 회 반복해 착륙 오차 분포(CEP) 산출
```

## 3. 지금까지의 주요 결과

> ⚠️ **수치 정정(2026-09-01)**: 이전 공유본의 몬테카를로 수치(보상 시 CEP ≈31 m 평탄,
> 81.4 m 등)는 집계 스크립트 라벨 버그로 **가정 통계(assumed)** 결과였음이 확인돼 전부
> 무효 처리했다. 아래 수치가 실측 보정 통계(calibrated) 기준의 공식 수치다.

### ① 최종 몬테카를로: τ 임계 구조 (P7b, 조건당 200회, 보정 통계)

직렬 처리 모델(AI가 사진을 처리하는 동안엔 다음 촬영 불가 — 현실 반영) 기준:

- **지연 보상 켜면**: τ ≤ 촬영 주기(1 s)에서는 CEP 110.8 m로 평탄. 주기를 넘으면
  프레임 드롭으로 악화 (τ=2 s → 177.8 m, 5 s → 250.4 m)
- **지연 보상 끄면**: τ에 단조 악화 — n INT8(196 ms) 159.9 m → s INT8(376 ms) 241.7 m
  → s FP32(537 ms) 323.0 m → τ=5 s면 2,160.5 m
- **오검출률 곡선**(연구계획서 산출물 ④): 오검출 0→30%에서 CEP 112.7→150.8 m

### ①-b 보상의 성립 조건 — "보상하면 그만"이 아닌 이유 (P7b+)

- **촬영시각 태깅 오차**: ≤20 ms면 무해, **200 ms(도착시각을 촬영시각으로 쓰는 구현
  실수 수준)면 보상이 미보상보다 오히려 나쁨**(194.9 vs 159.9 m), 500 ms면 349.5 m
- **카메라 레이트를 올리면**(측정↑ → CEP↓: 1 Hz 110.8 → 5 Hz 48.7 m) τ 예산이 조여져,
  **5 Hz에서는 양자화 하나(τ 23 ms 차이)가 CEP를 유의하게 가른다: n INT8 48.7 m(드롭 0)
  vs n FP32 65.7 m(드롭 50%)** — "mAP가 아니라 τ가 착륙을 가른다"의 직접 증거

### ② τ 벤치마크와 온보드 컴퓨트 맥락 (P2·P7b)

| 백엔드 | median τ | 결론 |
|---|---|---|
| GPU TensorRT INT8 | 54.5 ms | 지상 참조치 (착륙선엔 GPU 없음) |
| CPU 1스레드 n INT8 | 195.7 ms | 기준 조건 |
| CPU 1스레드 n FP32 | 219.0 ms | INT8 대비 +12% |
| CPU 1스레드 s INT8 | 376.5 ms | 큰 모델 — mAP는 n과 동급 |
| CPU 1스레드 s FP32 | 536.6 ms | 양자화로 −30% 단축 |

- GPU에선 INT8/FP16 이득 없음(병목이 전·후처리) — 정밀도 축소의 이득은 하드웨어 의존.
- 우리 CPU 1스레드는 CoreMark/Dhrystone 실측으로 **JAXA HR5000(SLIM 세대 우주용 CPU)의
  127배 = NASA 차세대 HPSC급** → 우리 τ는 "차세대 온보드" 프록시. 레거시 우주 CPU로는
  소프트웨어 AI 탐지 자체가 불가(τ 20 s급) — SLIM이 FPGA 전용 로직을 쓴 이유와 정합.
- SLIM 정합성 표: 측정 성공률 0.98 vs 14/14, CEP 110.8 m vs ~10 m — 자리수·경향
  비교(plausibility)로만 사용.

### ③ 착륙지 확정: JAXA SLIM 착륙점 (P3) — **이번 주 최대 결정사항**

- **착륙 목표점 = SLIM 실제 착륙점 (13.3160°S, 25.2510°E, LROC 위성 측정값)**
- 선정 이유: JAXA가 2024년 실제로 정밀착륙(핀포인트)에 성공한 곳 + **공개 논문(Acta Astronautica Vol.226, 2025)에 비행 결과 수치가 있어 우리 시뮬레이션과 정합성 비교가 가능** (예: 고도 500 m에서 항법 오차 <1 m, 최종 착지 55 m 이탈은 엔진 고장 탓이라 비교에서 제외)
- 2순위 남부고지대(−42°, 14°)도 동일 파이프라인으로 분석해 통과 확인(크레이터 642개) — 백업 확보
- 극지(북극 등 물 탐사 지역)는 데이터·조명·좌표근사 3가지 이유로 불가 → **연구 한계점으로 문서화** (docs/limitations.md)

실측 데이터 3.7 GB(SLDEM2015 고도지도, LROC WAC 영상, Robbins 크레이터 카탈로그 130만 개)를 내려받아 착륙지 주변 **340×60 km** 박스로 잘라 가공 완료:

- 크레이터 카탈로그(직경 ≥1 km): **566개**
- TRN 사용 고도 구간: **22~30 km** (통계 분석은 17 km를 가리켰지만 실런 검증에서 저고도
  측정 품질 붕괴가 확인돼 22 km로 상향 — "폐루프로 검증해야 한다"는 연구 주장의 실증 사례)
- 검증: 하강 궤적 전 구간에서 카메라 시야가 지형 데이터 안에 100% 포함 (초기 220 km 박스에서 궤적 일부가 밖으로 나가는 문제를 감사에서 발견 → 340 km로 확장해 해결)

## 4. 남은 일정과 크리티컬 패스

```
[지금 9/2] 발표 스토리보드 확정(docs/storyline.md 초안 완료)
   └→ 9/3~5: 문서 갱신(한계·선행연구·Q&A 사실집) + P8 슬라이드 자산·다이어그램
       └→ 시연 영상 mp4 (Unity 캡처 → 인코딩, 연구계획서 산출물 ⑤)
           └→ 9/10(목) 슬라이드 동결 → 9/12(토) 결선
```

- 증거(수치·그림)는 전부 확보됐고, 남은 것은 **발표물 제작**이다: 다이어그램 2장,
  시연 영상, 슬라이드 본문. 10월 본실험 후보(IMU 바이어스, 시간상관 오차, n=500,
  기하 불변량 매칭)는 docs/STATUS.md에 기록돼 있음.
